# Valentine Menu

Proyecto React + Vite: página tipo invitación para un Menú de San Valentín.

Colores: blanco, dorado y beige. No incluye versión para imprimir.

Pasos (Windows PowerShell):

```powershell
cd F:/DESARROLLO/Valentin-Day/valentine-menu
npm install
npm run dev
```

- Reemplaza las imágenes dentro de `public/photos` con tus fotos (mantén los nombres o actualiza las rutas en los componentes).
- Edita los textos del menú en `src/components/Menu.jsx`.
- Cambia colores en `src/App.css` si deseas otro tono de dorado o beige.

Si quieres, puedo: añadir animaciones, mejorar el modal de galería con flechas, o generar variaciones de estilo (minimalista, vintage).
